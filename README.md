# ZamFit Pro 🇿🇲

Professional fitness app built in Kitwe for CodeAlpha Internship.

![Logo](assets/icon.png)

## 📱 Download APK
Go to **Actions** tab -> Latest workflow -> Download `ZamFit-Pro-APK`
or **Releases** -> `app-arm64-v8a-release.apk`

## Features
- 10 Zambian workouts, Live BPM, Water tracker, Background timer
- 15MB, offline, Tecno optimized
- KITWE • CHAMPION MODE
